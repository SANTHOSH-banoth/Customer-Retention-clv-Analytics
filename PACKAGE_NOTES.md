# Package Notes — What's Included and How to Regenerate the Rest

## Test status

**All 149 tests pass** when the full pipeline has been run (verified
immediately before this zip was created). If you run `pytest src/ -q`
directly on this extracted zip, **some tests will fail with
`FileNotFoundError`** — this is expected, not a bug. See below.

## Why some large files are excluded

To keep this archive a reasonable size, three large, fully regenerable
files are **not** included:

- `data/raw/online_retail_II.xlsx` / `online_retail_ii.zip` (raw source
  data, ~44MB) — you already have this file.
- `data/raw/online_retail_ii_combined.pkl` (~135MB) — the ingested raw
  data, regenerated by `src/ingest.py`.
- `data/processed/transactions_classified.pkl` (~148MB) and
  `data/processed/transactions_with_revenue.pkl` (~156MB) — transaction-
  level intermediate tables, regenerated by `src/clean.py` and
  `src/revenue.py`.

Every other output in `data/processed/` (customer table, RFM, segments,
cohorts, CLV predictions, revenue-at-risk, retention simulation, country
analysis, reconciliation data, dashboard export) **is included**, since
those are the smaller, final analytical tables the reports and dashboard
are built from.

## How to fully regenerate the pipeline

1. Place the original `online_retail_ii.zip` (or `online_retail_II.xlsx`)
   in `data/raw/`.
2. From the project root, run the phases in order:
   ```
   python3 src/ingest.py
   python3 src/clean.py
   python3 src/revenue.py
   python3 src/customer_table.py
   python3 src/rfm.py
   python3 src/segment.py
   python3 src/cohorts.py
   python3 src/retention_matrix.py
   python3 src/clv_model.py
   python3 src/clv_validate.py
   python3 src/rfm_clv.py
   python3 src/revenue_at_risk.py
   python3 src/retention_simulation.py
   python3 src/country_analysis.py
   python3 src/naive_comparison.py
   python3 src/segment_migration.py
   python3 src/export_dashboard_data.py
   ```
3. Then `python3 -m pytest src/ -q` will show 149/149 passing, exactly as
   verified before packaging.

## Everything else in this archive is complete and self-contained

- `src/` — all 28 phase scripts + 21 test files
- `reports/` — all 28 phase reports (Markdown) + all figures (PNG)
- `dashboard/index.html` — fully self-contained interactive dashboard
